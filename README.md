# 拼豆图纸转换

微信小程序：把图片转换成拼豆（Perler beads / Hama beads）图纸。

## 功能

- [x] 上传或拍摄一张图片（JPG / PNG）
- [x] 滑块设定图纸尺寸，纵向按原图比例自动计算
- [x] 像素化 + CIE Lab 最近色匹配，生成带网格的拼豆图纸
- [x] 配色表：每个色号用多少颗，按用量排序
- [x] 保存图纸到相册（含行列坐标与配色表的高清大图）
- [ ] 限制最多用色数
- [ ] 按 29×29 底板自动分块
- [ ] 双指放大看单颗豆

## 色板说明

`utils/palette.js` 是 MARD 漫漫色号体系的 58 色，**RGB 为按常见色卡整理的近似值，不是厂商官方色值**。
拿到实物色卡后逐个校准即可，其它代码不用动；也可以只保留手上真正有的颜色，图纸就不会出现买不到的色号。

## 目录结构

```
├─ app.js / app.json / app.wxss   小程序全局配置
├─ project.config.json            开发者工具项目配置
├─ sitemap.json                   索引配置
├─ pages/
│  ├─ index/                      首页：选图 + 尺寸设置
│  └─ result/                     结果页：图纸画布 + 配色表 + 保存相册
└─ utils/
   ├─ palette.js                  拼豆色板（色号 / 名称 / RGB / Lab）
   └─ convert.js                  像素化与配色匹配核心算法
```

## 开发

1. 用微信开发者工具「导入项目」选择本仓库目录
2. 在 `project.config.json` 中填入自己的 AppID
3. 编译预览

> `project.private.config.json` 为本地私有配置，已在 `.gitignore` 中忽略。

## 环境要求

调试基础库 **2.16.1 以上**（用到了离屏 Canvas 2D）。
正式发布前需在小程序后台的「用户隐私保护指引」中声明相册写入权限。
